# Courier and Parcel Tracking — Java Terminal Version

This is the menu-driven Java console application for Scenario 26. It runs in the VS Code integrated terminal (no browser or Spring Boot server is needed for this version). It stores data in the same MySQL `courier_tracking` database used by the project.

## Menu options

1. Add customer
2. List customers
3. Register parcel
4. Assign delivery personnel
5. Update parcel status
6. Record delivery attempt
7. Track parcel
8. Shipment report
0. Exit

The menu appears again after each operation. Customer and parcel records are saved in MySQL.

## Requirements

- JDK 17 or newer
- Apache Maven 3.8 or newer
- MySQL Server 8 or newer
- VS Code (recommended) with Extension Pack for Java

## 1. Create the database

1. Start MySQL Server and open MySQL Workbench.
2. Open `../Database/schema.sql` from this project.
3. Execute the whole script. This script uses `CREATE DATABASE IF NOT EXISTS` and `CREATE TABLE IF NOT EXISTS`; it does not drop the database.
4. Optional: execute `../Database/sample_data.sql` if you want example customer, parcel and tracking records. Run sample data only once to avoid duplicate phone/tracking values.

## 2. Run from VS Code terminal (Windows PowerShell)

Open the `Java-Console` folder in VS Code, then choose **Terminal → New Terminal**. Run:

```powershell
$env:DB_URL = "jdbc:mysql://localhost:3306/courier_tracking?useSSL=false&serverTimezone=UTC"
$env:DB_USER = "root"
$env:DB_PASSWORD = "YOUR_MYSQL_PASSWORD"
mvn clean package
java -jar target/courier-parcel-tracking-1.0.0.jar
```

Replace `YOUR_MYSQL_PASSWORD` with your local MySQL password. Do not share or commit your password.

Alternatively, on Windows Command Prompt, run `run.bat` from this folder. It asks for your MySQL username and password, builds the app if needed, and starts it.

On macOS/Linux, run `./run.sh` from this folder (Maven must be installed).

The customer ID is generated by MySQL and may differ on your computer. To register a parcel, choose `3` and enter the sender customer ID returned by option `1` (or shown by option `2`). The app prints the generated tracking number; use that number with option `7` to track the parcel.

## Troubleshooting

- **`mvn` is not recognized:** install Apache Maven, restart VS Code, and check `mvn -version`.
- **Database connection failed:** ensure MySQL is running and check `DB_URL`, `DB_USER`, and `DB_PASSWORD`.
- **Unknown database/table:** execute `../Database/schema.sql` in MySQL Workbench.
- **Access denied:** verify your MySQL username and password.
- **Duplicate phone:** customer phone numbers must be unique; enter a different number.

This console app is separate from the Spring Boot web application in `../Backend`.
